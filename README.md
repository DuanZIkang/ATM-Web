# ATM-Web

一个适合 Java Web 初学者学习和练手的 ATM 模拟系统。

如果你刚学完 Java、Spring MVC，正在寻找一个适合自己动手实践的完整项目，那么欢迎了解 ATM-Web。

这是一个基于 Spring Boot + Vue 3 开发的前后端分离项目，通过模拟 ATM 的常见业务，让你了解一个完整 Web 应用的开发过程。

项目包含用户注册、登录、账户管理、存款、取款、转账、交易记录等功能，并提供 Docker 部署配置。

项目会持续维护和更新，希望能给正在学习 Java Web 的开发者提供一些参考。

## 项目功能

### 用户功能

- 用户注册与登录
- 查看个人账户信息
- 修改登录密码
- 查询账户余额

### 交易功能

- **存款**：向自己的账户存入指定金额。
- **取款**：从自己的账户中提取资金。
- **转账**：向其他用户的账户转入指定金额。
- **交易记录**：查看最近的交易记录，了解账户资金变动情况。

### 其他功能

- 前后端分离，前端通过 HTTP 请求与后端进行数据交互。
- 使用 JWT 进行用户身份认证。
- 使用 Redis 保存登录状态相关信息。
- 对用户密码进行安全处理。
- 后端进行业务数据校验，避免非法金额等数据影响账户。
- 使用 Docker 和 Nginx 部署项目。

## 项目结构

项目采用前后端分离的开发方式，前端和后端分别放在不同的目录中。

```
ATM-Web/
├── atm/                    # 后端项目
│   ├── src/
│   │   └── main/
│   │       ├── java/       # Java 源代码
│   │       └── resources/  # 配置文件及资源
│   └── pom.xml             # Maven 项目配置
│
├── atm-front/              # 前端项目
│   ├── src/
│   │   ├── components/     # 公共组件
│   │   ├── views/          # 页面
│   │   ├── router/         # 路由配置
│   │   └── utils/          # 工具类
│   ├── package.json
│   └── vite.config.js
│
├── Dockerfile              # 后端 Docker 镜像构建文件
├── Docker-compose.yml      # Docker 部署配置
└── README.md
```

### 后端代码结构

后端采用常见的分层开发方式，将不同职责的代码放在不同的位置。

| 目录         | 主要作用                       |
| ------------ | ------------------------------ |
| controller   | 接收前端请求，调用对应业务功能 |
| service      | 处理具体的业务逻辑             |
| service/impl | 业务逻辑的具体实现             |
| mapper       | 负责数据库查询和数据修改       |
| entity       | 存放账户、交易等实体类         |
| dto          | 接收和传递请求数据             |
| common       | 存放统一返回结果等公共代码     |

## 项目运行

如果想在自己的电脑上运行项目，需要提前准备以下环境。

### 环境要求

| 环境    | 版本或要求         |
| ------- | ------------------ |
| JDK     | 17                 |
| Maven   | 3.9+（建议）       |
| Node.js | 22+（建议）        |
| MySQL   | 需要提前安装并启动 |
| Redis   | 需要提前安装并启动 |

### 1. 获取项目

```bash
git clone https://github.com/DuanZIkang/ATM-Web.git

cd ATM-Web
```

### 2. 配置数据库和 Redis

首先创建 MySQL 数据库，并根据项目实际使用的表结构初始化数据表。

然后进入后端配置目录：

```
atm/src/main/resources/
```

项目通过 `application.yml` 指定运行环境，默认使用 `dev` 配置。

请根据自己的实际环境，修改对应配置文件中的：

- MySQL 数据库地址
- 数据库用户名和密码
- Redis 地址及端口
- 项目运行所需的其他配置

注意：不要将自己的数据库密码、JWT 密钥、AES 密钥等真实敏感信息提交到 GitHub。

### 3. 启动后端

进入后端目录：

```
cd atm
```

使用 Maven 构建项目：

```
mvn clean package
```

构建完成后，运行生成的 JAR 文件：

```
java -jar target/atm-3.2.0-RELEASE.jar
```

后端默认运行端口为：

```
8090
```

如果启动失败，请先检查 JDK 版本、数据库连接、Redis 连接和配置文件。

### 4. 启动前端

重新打开一个终端，进入前端目录：

```
cd atm-front
```

安装项目依赖：

```
npm install
```

启动前端开发服务器：

```
npm run dev
```

启动成功后，根据终端输出的本地地址访问前端页面。

默认情况下，Vite 会将 `/api` 开头的请求转发到本地后端的 `8090` 端口。

## Docker 部署

项目提供 Dockerfile 和 Docker Compose 配置，可以用于后端容器化部署以及配合 Nginx 提供 Web 服务。

相关文件：

- `Dockerfile`：用于构建后端镜像。
- `Docker-compose.yml`：定义后端和 Nginx 容器的运行方式。

需要注意，当前 Docker Compose 配置包含外部 Docker 镜像、Nginx 配置文件和外部数据卷等部署环境依赖，并不是适用于所有电脑的一键部署配置。

初次部署时，需要根据自己的服务器环境调整相关配置。

## 学习建议

如果你是刚学完 Java Web 或 Spring MVC 的初学者，可以尝试按照下面的顺序阅读项目：

1. 先从前端登录页面开始，了解页面如何向后端发送请求。
2. 找到后端对应的 Controller，了解如何接收请求和返回数据。
3. 进入 Service，查看登录、存款、取款等业务是如何实现的。
4. 查看 Mapper，了解后端如何操作 MySQL 数据库。
5. 最后尝试修改一个简单功能，观察修改前后的变化。

不需要一开始就理解项目中的所有代码，可以从自己熟悉的功能开始，逐步了解整个项目。
